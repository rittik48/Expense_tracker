# Smart Expense Tracker

A frontend-only SDC project implemented strictly with HTML5, CSS3 and JavaScript.

## Modules
- User Module
- Admin Module

## Features
- Signup and Login using LocalStorage
- Role-based JavaScript redirection
- Add, view, search and delete expenses
- Expense categories
- Monthly budget
- Category and monthly reports
- Admin user management
- Admin expense monitoring
- CSS Grid and Flexbox responsive UI
